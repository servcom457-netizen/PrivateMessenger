# PhilaSecret V2

Prototype Android natif Kotlin + Jetpack Compose.

### Ajouts par rapport à V1
- Écran de création de code PIN (4 à 8 chiffres) et déverrouillage pendant la session.
- Bouton pour verrouiller l'écran.
- Suppression d'une note.
- Compteur de notes.

### Limites de sécurité
Cette V2 est un prototype d'interface, pas un coffre-fort sécurisé. Le PIN et les notes restent en mémoire et disparaissent lorsque l'application est recréée. Le PIN n'est pas chiffré et les notes ne sont pas protégées par chiffrement. Ne stocke pas de données sensibles.

### Ouvrir
Décompresser le ZIP et ouvrir le dossier `PhilaSecret_V2` dans Android Studio.
